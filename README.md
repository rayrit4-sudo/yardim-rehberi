# Hangi Yardıma Hakkım Var

Türkiye'nin en büyük 20 ilinin büyükşehir belediye yardımları, resmi kaynak linkiyle.

- `data.js`: tüm yardımlar. Her kayıtta kaynak linki, kaynak tarihi ve durum (acik / guncel / kapali / eski) zorunlu.
- `check.js`: `node check.js` kaynaksız veya tutarsız kaydı reddeder.
- `index.html`: sayfa (bağımlılık yok, düz HTML).

Veri eklerken önce resmi belediye sitesine bak. Haber ile resmi sayfa çelişirse en yeni tarihli resmi kaynağı esas al ve notta yaz.
